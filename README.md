# PicTrait AI Community Edition

사진의 빛·색·질감을 자연스럽게 정돈하는 Windows용 사진 보정 프로그램입니다. 사진 처리와 AI 추론은 PC 안에서 이루어집니다.

## 다운로드

[최신 버전 다운로드](https://github.com/dwallet1212/PicTrait-AI/releases/latest)

- **설치형 EXE:** 설치 후 시작 메뉴의 **PicTrait AI Community Edition**으로 실행합니다.
- **무설치 ZIP:** 전체 압축을 새 폴더에 풀고 `PicTrait-AI.exe`를 실행합니다.
- Windows 10/11 x64용입니다. 회원가입·API 키·Python·AI 모델을 별도로 준비할 필요가 없습니다.

## 주요 기능

- AI 톤 보정과 자연스러운 선명도 조절
- AI 노이즈 제거와 렌즈 프로파일 보정
- AI 피사체 조명 및 대상 영역 확인·수정
- 밝기·비네팅 −5.00~+5.00 직접 입력과 0 초기화
- 원본 비교, 정밀 확인, 라이브러리와 여러 사진 내보내기
- 내보낼 때 가로·세로 2배 AI 업스케일링

원본 사진은 보존하며 보정한 결과물을 별도로 내보냅니다.

## 배포 구성

설치 패키지는 앱 실행 코드, 런타임, AI 모델, 필수 UI 아이콘 및 라이선스 고지만 포함합니다. 개발·검사 도구, 예제 사진, 설계용 리소스, 내부 문서, 설명서 사본과 바로가기 생성 스크립트는 제외했습니다. 설명서는 이 저장소에서 제공합니다.

개인용 V1.0과 설치 위치·편집 데이터를 분리했습니다. 커뮤니티 설치형과 무설치형끼리는 같은 편집 데이터를 사용합니다.
